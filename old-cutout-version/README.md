# Old cut-out version (rejected)

This is the first try at *The Fallen Star* (2026-10-08): paper cut-out puppets in Remotion + GSAP.
bear rejected it ("cards just jiggle"), and the film was remade with the painted engine in the main folder.
It is kept only for the record.

It was built inside the Sheep in the Box project, so to run it, copy `src2/`, `sound2/` and `render2/`
into a checkout of [sheep-in-the-box-film](https://github.com/bear20252026/sheep-in-the-box-film)
(it uses that project's `public/img/` art), make the sound with `python3 sound2/sNN.py public/audio2/sNN.wav`,
and render with `bash render2/runq.sh`.
